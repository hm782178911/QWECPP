# 两卡 PP 第一阶段
单进程顺序执行两个连续层阶段。每阶段拥有独立 GPU 权重缓存、cuBLAS 句柄和默认 stream；进入/退出阶段恢复调用方设备。Embedding 只在第一阶段，最终 RMSNorm 和输出投影只在最后阶段。tied 权重跨设备各存一份；单卡时复用缓存。阶段间优先 P2P，缺失时固定页主机中转，先明确同步保证正确。默认按层均分，也允许指定合法切分边界和设备次序。保留单卡模式、无 KV Cache 和 256 token 上限。本阶段无多请求重叠调度，不承诺单请求加速。
验证：单卡对照两卡、反向设备次序、强制主机中转、边界切分、完整 logits 和多轮聊天、内存检查及非法选项。
